# Debt Risk Management – Project Portfolio

This folder contains a collection of analytical projects focused on credit, market, and operational risk modeling. The repository includes statistical model implementations and comprehensive analyses of risk exposure measures.

## Project Overview

| Project | Description | Report Preview (HTML) |
| :--- | :--- | :--- |
| **1. VaR Estimation Techniques** | Comparative analysis of Value at Risk (VaR) and Expected Shortfall (ES) calculation methods at various confidence levels. | [View Report](https://htmlpreview.github.io/?https://github.com/Laszczyk/Debt-risk-management-/blob/main/projekt1.html) |
| **2. Scoring Models** | Development of credit decision-making classifiers using KKNN, Logistic Regression, and Cutoff optimization. | [View Report](https://htmlpreview.github.io/?[YOUR_REPO_URL]/projekt2.html) |
| **3. Portfolio Risk Management** | Estimation of VaR and ES for multi-asset portfolios, focusing on asset correlation and diversification effects. | [View Report](https://htmlpreview.github.io/?[YOUR_REPO_URL]/projekt3.html) |
| **4. Operational Risk (AMA)** | Implementation of the Advanced Measurement Approach (AMA) to model operational losses across different business lines. | [View Report](https://htmlpreview.github.io/?[YOUR_REPO_URL]/projket4.html) |
| **5. Bankruptcy Prediction (LDA)** | Applying Linear Discriminant Analysis (LDA) and classic financial models (Altman, Hołda, Prusak) to predict insolvency. | [View Report](https://htmlpreview.github.io/?[YOUR_REPO_URL]/Modele-oparte-na-LDA.html) |

## Methodology & Tools
* **Language:** R / RMarkdown
* **Risk Metrics:** VaR (Value at Risk), ES (Expected Shortfall), Operational VaR
* **Statistical Models:** Linear Discriminant Analysis (LDA), KKNN, Logistic Regression
* **Bankruptcy Forecasting:** Altman Z-Score, Hołda Model, Prusak Model
* **Optimization:** Sensitivity analysis, correlation impact assessment, and optimal cutoff points
